# Lamsa Advertising Website

An Arabic RTL advertising and marketing website designed to present creative marketing and advertising services.

## Project Overview

Lamsa Advertising Website is a multi-page Arabic RTL website created for a fictional advertising and marketing company. The project focuses on presenting the company's services, information, clients, blog content, and contact options through a clear and organized web interface.

## Pages

- Home
- About Us
- Services
- Service Details
- Blog
- Contact Us
- Complaints & Suggestions

## Technologies & Tools

- HTML5
- CSS3
- Figma
- Git & GitHub
